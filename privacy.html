Privacy Policy

Last updated: September 27, 2026

"n8n local" is a personal automation tool run on the owner's own computer and used only by the owner.

Data accessed

With the owner's permission, the app uses Google Drive to upload files into the owner's own Drive, and Gmail to send emails from the owner's account to the owner.

Data storage and sharing

OAuth tokens are stored only on the owner's local machine. No Google user data is sold, shared with third parties, or used for advertising. No data from any other user is collected.

Revoking access

Access can be revoked at any time from myaccount.google.com/permissions.
